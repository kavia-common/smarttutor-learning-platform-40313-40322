# Backend Links for Local Dev

When the Flask backend is running locally:
- Health: http://localhost:8000/health
- OpenAPI JSON: http://localhost:8000/openapi.json
- Diagnostics:
  - Ping: http://localhost:8000/diag/ping
  - Headers: http://localhost:8000/diag/headers
  - Version: http://localhost:8000/diag/version
- Whiteboard:
  - Sessions: http://localhost:8000/api/whiteboard/sessions
