# SmartTutor Flutter Container

This directory contains the minimal Flutter app setup required for CI builds.

- Entry point: `lib/main.dart`
- Theme: Ocean Professional (primary #2563EB, secondary/accent #F59E0B)
- Pubspec configured for Flutter app builds.

To regenerate full platform files locally, you can run:
```
flutter create .
```
Do not modify CI/start scripts as per project guidance.
