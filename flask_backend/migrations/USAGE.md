# Alembic Usage

Common commands:
- Create new autogenerated revision:
  alembic revision --autogenerate -m "your message"

- Apply migrations to latest (head):
  alembic upgrade head

- Downgrade one step:
  alembic downgrade -1

- Show current revision:
  alembic current

Notes:
- Ensure flask_backend/.env is configured with a valid DATABASE_URL before running commands.
- Models are imported in app/__init__.py to ensure autogenerate can detect changes.
