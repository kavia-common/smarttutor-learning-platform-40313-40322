# SmartTutor Flask Backend – Documentation and Diagnostics

This backend provides diagnostics, OpenAPI discoverability, and helper scripts.

Key endpoints:
- Health and status
  - GET /health
  - GET /api/status
  - GET /api/version
- OpenAPI
  - GET /openapi.json
- Diagnostics
  - GET /api/uptime
  - GET /api/memory
  - GET /api/metrics
  - GET /api/proc
  - GET /api/cpu
  - GET /api/routes

OpenAPI:
- Generated by app/openapi_register.py using app/openapi.py and merged with app/openapi_extra_paths.py.
- Fetch it: curl -s http://localhost:8000/openapi.json | python -m json.tool

Scripts:
- scripts/print_config.py: Prints sanitized config
- scripts/check_migrations.py: Alembic history
- scripts/verify_models.py: Lists model tables
- scripts/table_counts.py: Counts by table
- scripts/smoke_all_in_one.py: Hits core endpoints
- scripts/fetch_routes.py, fetch_proc.py, fetch_cpu.py, fetch_metrics.py: Single-endpoint fetchers
- scripts/write_openapi_file.py (add below) will save openapi.json locally for CI or docs.

See BACKEND_SMOKE.md and ENV_VARS.md for quick start and environment setup.
